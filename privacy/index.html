Tabwren privacy policy

Tabwren is a local record and limits for checkouts in this browser. That is its single purpose. The price shown on a page is part of that record.

Tabwren keeps the log on this device. There is no account. Nothing is sent to a server. There is no telemetry.

The record can include the merchant, date, amount, reference, item names, the page address, the price shown, a source note, and whether a pause was up. These are financial and transaction details, and the page address is web history. They stay in this browser profile.

A source note can name the assistant page that opened the tab. It can say Sponsored when that page showed a short Sponsored, Promoted, or Advertisement label. Sponsored-answer visits are counted on the monthly card.

A monthly card on this device counts checkouts, pauses, private-window checks, and sponsored-answer visits. Dollar amounts stay off that card unless you turn them on. The card is a local snapshot, not a score.

Password fields and card-number fields are skipped. The release phrase is stored only as a hash and is not shown on checkout pages.

Whether a pause is on for an open tab is kept in this browser's extension storage for the session. That record is kept by the extension, not on the page. It is not sent off the device.

On sites you allow, confirmation pages are logged whether or not agent mode is on. The pause is added only while the agent mode switch is on and a limit you set is crossed.

The pause cover is an element in the page, so a script on that page may be able to see that the pause is up. A same-origin frame can also reach the pause check kept on the submit function.

Use of this information follows the Chrome Web Store User Data Policy, including the Limited Use requirements.

Limited Use: the data is not sold, is not transferred except when you download a file to this computer, is not used for credit or ads, and stays on the device.

Tabwren uses this information only to provide that single purpose. No person at Tabwren reads the log. Removing the extension removes its local storage.

A private-window price check opens the same address in a private window on this device and shows both amounts. Prices can differ for many reasons, including location, stock, promotions and tests. This shows a difference, not the cause.

Agent mode is a switch you turn on. Tabwren does not turn it on by itself, and it does not detect agents.

When agent mode is on and an order crosses a limit you set, a full-screen hold covers Place Order on that page. To release it, you type your phrase. Paste is refused. In our tests it stopped clicks, Enter, scripted clicks and form submits aimed at Place Order. It does not stop: anyone, or any tool, that already knows your phrase and types it; code on the page that sends the order directly or opens the confirmation address; payment buttons inside another company's frame, such as a card or wallet window; checkout pages where Tabwren doesn't recognize the order button, for example one labeled Continue. On a checkout it does look for Submit payment, Pay now, Complete purchase, Confirm and pay, and Buy now, and for Zahlungspflichtig bestellen, Jetzt kaufen, Pagar ahora, Paga ora, Commander, and Acheter. A Buy button on a product page is not paused merely because it says Buy, including Buy now, Jetzt kaufen, and Acheter; tools that control the browser through remote debugging. Treat the hold as a pause that asks a person to look, not as a lock. It never cancels or refunds an order.

It does not cancel, reverse, or refund anything.

Works inside this browser while running; can't see purchases made elsewhere or through direct payment connections.
